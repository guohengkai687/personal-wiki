# 录入使用说明（input/）

## 这是什么

`index.html` 是一个**纯前端生成器**：浏览器打开、填写、点按钮，生成并**下载**一条记忆 JSON。
它不会写盘、不出网 —— 落盘与登记由 `pipeline/helpers/ingest.py` 完成（见项目 README「快速开始」）。

## 怎么用

1. 用浏览器打开本目录的 `index.html`（双击即可；`file://` 下自动使用内嵌 schema 副本，功能一致）。
2. 四个区块：
   - **① 基础信息**：人物（真名）、关系；若勾选「新建人物」请填假名（展示层用）；日期时间、记录类型、场景类型/地点/说明。
   - **② 事件主体**：STAR（情境 / 原话 / 行动 / 结果）。原话与行动至少填一个。
   - **③ 人物观察**：行为标尺（直接/理性/主动，1-5 分）、情绪状态、补充观察；勾选「敏感/私密」则该记忆永不入库。
   - **④ 评价与后续**：优点 / 弱点 / 总结（务必写"我的观察依据"而非空泛词）、标签、待跟进、关联人物。
3. 点「校验并生成 JSON」，浏览器自动下载文件（私密记忆文件名带 `-PRIVATE`）。
4. 把下载的文件交给摄入：
   ```
   python pipeline/helpers/ingest.py <下载的.json>
   ```
   新人物请用 `--ref <ref>` 指定并加 `--add-alias`。

## 校验规则（form-schema.json）

- 必填：人物、关系、日期时间、记录类型、场景类型、场景说明、情境、优点、总结；
- 原话与行动至少其一；评价含「还行/不错/挺好/一般」等空泛词会拦截；
- 标签最多 8 个，可自定义。

## schema 说明

`form-schema.json` 是字段定义与校验的唯一真源（ingest.py 的二次校验也读它）。
`index.html` 在 `file://` 下使用内嵌副本 —— 修改 schema 后请同步更新 `index.html` 内嵌副本
（或始终通过 `python -m http.server` 访问以获得实时 schema）。
