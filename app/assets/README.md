# app/assets —— 素材来源与许可

本目录素材均从网络获取并本地打包，保证程序离线可用。

## 图标（icons/）— Tabler Icons（MIT）

- 来源：<https://cdn.jsdelivr.net/npm/@tabler/icons@2.47.0/icons/*.svg>
- 许可：MIT License（<https://github.com/tabler/tabler-icons/blob/main/LICENSE>）
- 用途：界面标签页 / 按钮 / 统计卡图标。

## 字体（fonts/）— 开源 OFL 字体

| 文件 | 字体 | 来源 | 许可 |
|---|---|---|---|
| `Inter.ttf` | Inter（可变字重） | <https://github.com/google/fonts/tree/main/ofl/inter> | SIL OFL 1.1 |
| `NotoSansSC.ttf` | Noto Sans SC（可变字重） | <https://github.com/google/fonts/tree/main/ofl/notosanssc> | SIL OFL 1.1 |

- OFL 1.1 允许自由嵌入 / 再分发（见各字体的 LICENSE/OFL.txt）。
- 若字体加载失败，界面自动回退到系统字体（微软雅黑），不影响使用。
