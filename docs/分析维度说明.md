# 分析维度说明

> 人物分析的全部维度、含义与打分规则。Agent（opencode）与人工作对照共同使用，目标是**可复现、可溯源、防过度推断**。
> 维度定义见 DESIGN.md §6.3，任务书见 `pipeline/analyze.md`。

## 0. 通用规则（先读）

1. **打分一律 1-5 分**，只能依据证据（记忆 ID / m 序号）支撑的判断打分；
2. **置信度**：高 = ≥3 条一致证据；中 = 2 条；低 = 1 条或纯推断；
3. 推断类结论一律标注 `🧊 推断 + 置信度`，禁止把猜测写成事实；
4. **样本 < 3 条时**，档案整体置信度默认"低"，并显式写「待积累证据后复核」；
5. 无法判断的维度用 `-` 占位，**绝不为了凑数而强行打分**。

## 1. 大五人格（Big Five，各 1-5 分）

| 维度 | 低分（1-2） | 高分（4-5） | 主要证据来源 |
|---|---|---|---|
| **开放性** | 守旧、依赖既有做法、少创新提议 | 乐于探索新方案、接受他人新想法 | 决策模式、subject.quote/action |
| **尽责性** | 拖延、少跟进、承诺含糊 | 守约、主动推进、关注细节与终点 | 承诺兑现、follow_up、主动同步 |
| **外向性** | 安静、回避社交、精简互动 | 健谈、主动连接、爱寒暄 | 沟通风格、场景中的主动度 |
| **宜人性** | 竞争、质疑、少让步 | 合作、体谅、易于达成一致 | 冲突处理、result |
| **神经质** | 情绪稳、抗压 | 情绪起伏大、易紧张焦虑 | 情绪特点、压力反应 |

## 2. 沟通风格

- **直接度**：结论先行 vs 铺垫迂回（对照 observation.demeanor.direct）
- **信息密度**：附带的数据 / 细节 / 案例量
- **寒暄偏好**：对话是否含无关开场与寒暄
- **修辞习惯**：口头禅、缓冲语（如"技术上不可行"）、引用数据 / 类比等

## 3. 决策模式

- **风险偏好**：冒险 vs 规避（例：是否接受变通路径、是否愿意推倒重来）
- **信息依赖**：决策前需要的证据 / 他人评估量
- **决策速度**：当场拍板 vs 拖到会后

## 4. 冲突处理

- **方式**：正面（直面争议）/ 回避（绕开）/ 转移（把冲突转移到技术、事实、流程层面）
- **压力反应**：被质疑时的典型表现（防御性反驳 / 沉默 / 改用数据说话 / 让步）

## 5. 情绪特点

- **稳定性**：情绪起伏大小
- **表达度**：情绪是否外露
- **压力反应**：高压 / 被追问时的典型表现

## 6. 合作价值

- **可依赖度**：承诺兑现率、交付质量、是否主动预警
- **需补位点**：他习惯性空白 / 短板，以及"我"该怎么补（具体到动作）

## 7. 输出纪律

- 档案必须套用 `pipeline/analyze.md` 的人物档案模板；
- 每条结论紧跟 `[m序号]` 证据（m 来自 `data/meta/register.json`）；
- 旧结论与新证据冲突时：不删旧结论，追加"行为变化趋势"标注，并以近 3 个月记忆为准。
